# О проекте — бриф content-strateg

**Название** — content-strateg (контент-завод): фреймворк субагентов Claude Code для
контент-конвейера.

**Проблема** — производство контента у эксперта/редактора хаотично: нет единого процесса от
идеи до публикации, факты не проверяются системно, легко нарушить закон о рекламе или авторское
право, а у клиентских проектов свои жёсткие редполитики, которые держатся «в голове». Нужен
управляемый конвейер с встроенными проверками качества и человеческими чекпоинтами.

**Пользователь** — журналист / редактор / эксперт, ведущий личный бренд и клиентские проекты
(медиаправо, контент-маркетинг, образование), работающий в Claude Code и желающий поставить
выпуск контента на поток без потери качества и правовой чистоты.

**Основная функция** — провести материал по стадиям
`стратегия → ресёрч → производство → fact-check → экспертное ревью → редактура → дистрибуция`
силами 6 специализированных субагентов под управлением дирижёра `/content-pipeline`, с паузой на
«да» владельца после каждой стадии и передачей артефактов через файлы проекта.

**Формат результата** — готовый к публикации пакет в папке проекта: проверенная фактура
(`research.md`), материалы под площадки ядра (Telegram / YouTube / Instagram), план дистрибуции,
статусы fact-check и ревью в `pipeline.md`. Система **ничего не публикует сама** — отдаёт текст на
финальное решение человека.

**Минимальный функционал** — 6 агентов + команда-дирижёр + 14 шаблонов артефактов + методология в
`CLAUDE.md` (классы контента, иерархия источников, запрет фабрикации и публикации, биндинг
клиентской редполитики, человеческая стадия экспертного ревью с правом вето).

**Технологии** — Markdown + YAML-фронтматтер, Claude Code sub-agents (`.claude/agents/*.md`) и
slash-команды (`.claude/commands/`), модели Opus / Sonnet по нагрузке; опциональные read-only MCP
(similarweb, ahrefs, Apify); Git + GitHub CLI для публикации. Лицензия CC BY 4.0.
